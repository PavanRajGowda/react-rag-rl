Run configuration and metric definitions
Number Match ignores sign and powers of ten, using the existing saved score. Signed numeric: |prediction − gold| ≤ max(10⁻⁶, |gold| × 0.01), with Yes/No mapped to 1/0. Exact match only collapses whitespace. Skipped and unsupported-gold rows are excluded from accuracy; scored technical failures remain included.
Reference retrieval means exact canonical context-ID match. Alternative evidence may be valid. This dataset does not provide a verified set of all required contexts. Active evidence is measured from the actual answer generation; questions with no answer are N/A. Unknown fields stay N/A.
Format compliance replays the current parser against saved outputs; historical parser versions may differ. Closed-book outputs use the same action parser, with search actions disallowed. Format is independent of answer correctness.

Reference retrieval and later-search recovery
Recovery: first search misses the canonical reference and a later search finds it. Denominator: searched questions with a first-search miss; excludes no-search questions. Recovery measures iterative retrieval, not proof of reasoning hops.

Observed search failures and fallback
Counts are events and may overlap. Wrong issuer/year cannot be inferred reliably from an empty result; inspect the response and evidence.


Numerical reasoning dependency depth
Depth is the longest calculation chain leading to the final gold-program result. Depth 1: direct calculation. Depth 2+: dependent multistep numerical reasoning (reasoning hops). This does not measure required retrieval hops. Original/reformulated question meaning has not been verified.
Total program operations (separate from dependency depth)
Parallel calculations increase operation count without necessarily increasing reasoning depth.
Time and generation length
Episode time includes tool waits, excludes startup. Input-token totals include repeated history. Missing timings are not replaced with zero.
